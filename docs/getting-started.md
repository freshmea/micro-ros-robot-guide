# 시작 안내

현재는 실행 예제 공개 전 단계입니다. 이 저장소에서 cmake 또는 colcon build를 실행해도 교육용 펌웨어·패키지가 생성되지 않습니다.

1. BOOK.md에서 책의 범위를 확인합니다.
2. docs/references.md의 기준 코드를 읽습니다.
3. docs/validation.md에서 검증 상태를 확인합니다.

첫 예제가 검증되면 정확한 OS·ROS·SDK·FreeRTOS 버전, 의존성 준비, 빌드·업로드, Agent 실행, 기대 로그와 종료 절차를 이 문서에 추가합니다. 개인 네트워크 설정은 config/README.md를 따릅니다.
