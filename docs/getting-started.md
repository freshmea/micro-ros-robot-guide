# 시작 안내

이 저장소는 안내 문서와 1–3장 무료 샘플을 제공합니다. 실행 가능한 교육용 통합 펌웨어·ROS 2 호스트 패키지는 아직 공개되지 않았습니다. 이 저장소에서 `cmake` 또는 `colcon build`를 실행해도 책의 펌웨어·패키지가 생성되지 않습니다.

## 샘플 읽기

1. [책 소개](../BOOK.md)에서 책의 범위와 집필 상태를 확인합니다.
2. [24장 목차](chapters.md)에서 로컬 제어부터 통합·재현까지의 학습 경로를 살펴봅니다.
3. [1–3장 무료 샘플 PDF](../samples/micro-ros-robot-ch01-03-sample.pdf)를 읽습니다. 로봇의 임무 정하기, Pico 2 W 개발 환경, 로봇 제어에 필요한 Embedded C를 다룹니다.
4. [검증 현황](validation.md)에서 PC 검사·호스트 통신·보드 및 실물 시험을 구분합니다.

## 3장 PC 논리 실습

샘플 3장에 수록된 전체 C 코드를 PDF의 안내에 따라 직접 파일로 저장하고, Ubuntu 또는 WSL의 PC용 C 컴파일러로 빌드·실행합니다. 보드 연결과 이 저장소의 펌웨어 빌드가 필요하지 않은 독립 실습입니다. 정확한 저장 파일명·컴파일 명령·기대 출력은 샘플의 각 코드 안내를 따릅니다.

경고를 켜고 정상값·경계값·거부 입력과 실패 후 상태 보존을 확인합니다. 명령 생성 예제의 `command checks passed`, 정지 상태 예제의 `boundary and stop checks passed`는 해당 PC 논리 검사의 결과입니다. GPIO·PWM·FreeRTOS 동시 실행·실물 정지 성공을 뜻하지 않습니다.

## 보드 실습을 준비할 때

[기준 코드와 공식 자료](references.md)를 먼저 확인합니다. 샘플의 개발 환경·보드·언어 비교는 학습을 위한 안내이며, 모든 보드나 언어 조합을 실물 검증했다는 뜻이 아닙니다. ROS 배포판·Pico SDK·FreeRTOS·툴체인의 최종 통합 조합도 확정 전입니다.

교육용 실행 예제를 공개할 때에는 검증한 버전, 의존성 준비, 빌드·업로드, Agent 실행, 기대 로그와 종료·복구 절차를 함께 안내합니다. 개인 네트워크 설정은 [설정 안내](../config/README.md)를 따릅니다. 실제 SSID·비밀번호·호스트 주소는 공개 파일에 적지 않습니다.
