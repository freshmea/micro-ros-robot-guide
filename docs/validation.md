# 검증 현황

2026-09-30 기준입니다. 책은 **집필 중이며 6부 24장 본문 초안**이 있습니다. 현재 공개 범위는 안내 문서·목차·검증 현황과 [1–3장 무료 샘플 PDF](../samples/micro-ros-robot-ch01-03-sample.pdf)입니다.

아래 PC·호스트 결과는 집필 과정에서 수행한 검사 기록을 요약한 것입니다. 이 공개 저장소에 전체 예제·시험 프로그램이 배포되어 있다는 뜻은 아닙니다. 원본 참고 코드의 과거 성공 기록도 현재 책의 통합 재현 성공을 대신하지 않습니다.

## 확인한 범위

| 항목 | 상태와 범위 |
|---|---|
| 원고 진행 | 1–24장 본문 초안 작성, 교정·검증 진행 중 |
| 기준 코드 검토 | 공개 참고 코드 커밋 `393f96b6e484b5c70245b821dddd3aca2d7cc1fc` 기준 |
| PC 논리 예제 | C 9개와 Python 3개, CTest 12/12 통과 기록. 입력·범위·상태·메모리·계산 등 PC 논리 검사 |
| ROS 2 호스트 예제 | Jazzy에서 동일 프로세스와 별도 두 프로세스의 요청·응답 및 응답자 부재 timeout 확인 기록 |
| 샘플 3장 C 실습 | PC에서 입력 경계·명령 생성·거부 시 상태 보존·정지 상태를 확인한 예제를 수록 |
| 도서 출력 | 초안 EPUB/PDF 생성과 구조·레이아웃 검사 기록이 있음. 출판 승인·인쇄 검수 완료를 뜻하지 않음 |

ROS 2 호스트 시험은 단일 호스트에서 수행했으며 MCU·Agent·직렬·Wi-Fi를 사용하지 않았습니다. PC 예제 통과로 GPIO·PWM·FreeRTOS 태스크·IRQ·보행이 검증된 것은 아닙니다. 샘플의 개념 삽화와 계산 예시도 확정 회로·CAD·실측 결과와 구분합니다.

## 미실시 또는 남은 확정

| 항목 | 상태 |
|---|---|
| Pico 2 W 최소 펌웨어 크로스 빌드·UF2·보드 실행 | 미실시 |
| USB 전달·업로드·LED와 로그·복구 | 실물 시험 미실시 |
| MCU·Agent 직렬 통신 | 실물 시험 미실시 |
| Wi-Fi·UDP·FreeRTOS 통합 및 재접속 | 미실시 |
| 전원·관절 보정·정지 지연·주변장치 | 실물 시험 미실시 |
| 고정형 로봇 제작·이족보행형 로봇 보행 | 실물 시험과 독립 재현 미완료 |
| SDK·FreeRTOS·Agent·정적 라이브러리·툴체인 조합 | 통합 검증 후 확정 |
| 누적 MCU 통합 펌웨어·ROS 2 호스트 패키지 | 교육용 구현·공개 준비 중 |
| 최종 BOM·배선·CAD·보행 수치 | 실물 검증 후 확정 |
| Rust 펌웨어·비교 보드·Microduck | 문서·소스 조사 범위, 이 책에서 빌드·실물 재현 미실시 |
| 전자책 앱별 확인·출판용 기술 교정·인쇄소 검수 | 후속 작업 |

실행하지 않은 시험은 통과로 표시하지 않습니다. [시작 안내](getting-started.md)의 샘플 실습부터 범위를 나누어 확인하고, 보드·통신·실물 시험은 환경과 관찰 증거를 갖추어 별도로 기록합니다.
