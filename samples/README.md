**ROS 2와 Raspberry Pi Pico 2 W로 만드는 micro-ROS 로봇**

Embedded C·FreeRTOS·micro-ROS로 배우는 고정형 로봇·이족보행형 로봇 설계와 제작

저자 **최수길** · 출판사 **마담** · **집필 중**

ISBN과 발행일은 미정입니다. 이 샘플은 집필 중인 초안의 일부로, 내용과 편집은 바뀔 수 있습니다.

## 수록 범위

- 1장. 내가 만들 로봇의 임무를 정한다
- 2장. Pico 2 W 개발 환경과 재현 가능한 버전
- 3장. 로봇 제어에 필요한 Embedded C

전체 구성은 [6부 24장 목차](../docs/chapters.md)에서 확인할 수 있습니다. 4–24장의 본문·전체 도서·편집 및 그림 원본은 이 공개 자료에 포함하지 않습니다.

## 실습과 검증 범위

3장에는 PC에서 직접 저장·컴파일·실행할 수 있는 C 코드와 안내를 수록했습니다. 보드를 연결하지 않고 입력 경계·명령 생성·정지 상태를 확인하는 논리 실습입니다. 공개 저장소에 완성된 보드 펌웨어나 ROS 2 호스트 패키지가 있다는 뜻은 아닙니다.

보드 빌드·Agent 통신·Wi-Fi·FreeRTOS 통합과 실물 로봇 제작·보행 검증은 완료되지 않았습니다. 시작 전에 [시작 안내](../docs/getting-started.md)와 [검증 현황](../docs/validation.md)을 읽어 주세요.

도서 본문·표지·그림의 권리는 각 저작권자에게 있습니다. 공개 범위와 출처는 [이용 안내](../NOTICE)를 확인하세요.
